# Thesis-appendix LaTeX documentation for `synthobj`

## Context

`synthobj` is complete (branch `feat/synthetic-objectives`, HEAD `fdabd86`, 297 tests). Its only
user-facing documentation is one README section plus docstrings. The user wants **detailed
documentation as LaTeX for the thesis appendix**, covering all four of: the construction with full
derivations, a reference for the 14 study variants, the API and file format, and the design
decisions. No thesis `.tex` skeleton exists anywhere in the repo or `Research Context/`, so the
deliverable is a standalone, `\input`-able fragment plus a wrapper for compile-testing.

Two findings from exploration shape everything below:

- **The load-bearing concepts are nowhere in prose.** The ANOVA / first-order Sobol decomposition
  that defines "variance share" is used as a known term in every docstring and defined in none;
  `v(ℓ)`, the normalization the thesis's central claim rests on, is asserted in code
  (`kernel.py:60-66`) and derived nowhere. Both become first-class derivations.
- **Quoted numbers drift.** The Plan agent re-measured and found the rotation-angle
  `gamma_axis` ranges in the ledger (20 seeds) differ from the archived grid (seeds 0–9, D=100:
  θ=15 → [0.100, 0.208] med 0.158; θ=45 → [0.335, 0.646] med 0.481); the realized/theory slope
  ratio has three values in the ledger (1.81 / 1.66 / 1.634±0.081); the 140-file QMC sweep is
  2^15 in one place and 2^16 in another. **No number may be typed by hand** — every table and
  every prose figure is generated by a script that can be diffed against the code.

Notation authority: `Research Context/research direction/Design-brief.md` (86 lines). It already
uses $\nu=U[0,1]$, $k_\ell$, $\tilde k_\ell$, $v(\ell)=1-\mathbb E_{x,x'}k_\ell$,
$\bar k_i=\tilde k_{\ell_i}/v(\ell_i)$, $a_i$, $s_i$, $g_i$ (slope share), $\gamma$, $c_{ij}=\sqrt{s_{ij}}$,
$S$, $I$, $f^\star$, $\rho_i=\ell_i^{-2}$, $w_q$, $t_q$. The appendix reuses these; it introduces
(once, flagged as new) $\hat\nu$ (the 64-node discrete measure), $r_i$ (raw draw — the brief
overloads $g_i$ for this), $\kappa$ (`scale`), $\mu$ (`mu`), $\theta$/$R_\theta$, $\phi_p$ (a paired
block), $s_i^{\mathrm{axis}}$, $\gamma^{\mathrm{axis}}$, $G$ (knot count), $n_{\mathrm{ext}}$.

Toolchain: TeX Live 2024 present (`pdflatex`, `latexmk`; amsmath/amssymb/booktabs/siunitx/
hyperref/cleveref all resolve). Python: `/opt/anaconda3/envs/saasbo/bin/python`.

Fragment rules: labels `app:so:<part>:<name>`; no `\documentclass`/`\begin{document}`; no
`\cite`; no siunitx in fragments (Python pre-formats numbers; booktabs only); no raw
`\mathrm{Var}`/`\sigma`/`\lambda` — the lint greps for symbols that bypass the macros.
`regen_tables.py` builds objectives in-process with `make_family` (12 s for the grid) so it
never depends on the git-ignored `data/`; if `data/objectives/manifest.json` exists it also
reports whether the rebuilt files hash-match it.

## Document outlines

### A1 Construction guide — one derivation per subsection, each ending "Code: … Test: …"

- **A1.1 Reference measure and quadrature.** $\nu$, $\hat\nu=\sum_q w_q\delta_{t_q}$ (64-node GL,
  exact to degree 127). Code `kernel.GL_NODES/GL_WEIGHTS`, `nu_mean`, `nu_var`.
- **A1.2 Centered kernel and $v(\ell)$.** $\tilde k = k - \mathbb E_z k(x,z) - \mathbb E_z k(z,y)
  + \mathbb E_{z,z'}k$ (projection form, Lu et al. 2022 eq. 8). Then
  $\mathbb E_x\tilde k(x,x) = 1 - 2\mathbb E k + \mathbb E k = 1 - \mathbb E_{x,x'}k =: v(\ell)$,
  so $\bar k=\tilde k/v$ has unit average marginal variance. Large-$\ell$: $k\approx
  1-\tfrac{5}{6\ell^2}(x-y)^2$, projection of $(x-y)^2$ is $-2(x-\tfrac12)(y-\tfrac12)$, hence
  $\tilde k\to\tfrac{5}{3\ell^2}(x-\tfrac12)(y-\tfrac12)$ and $v\to 5/(36\ell^2)$; the $r^3$ term
  explains the slow approach (ratio 0.958 at ℓ=3). Table `tab_v_ell`. Code `kernel.centered`,
  `v`, `normalized` (verbatim from the Gate-1 script). NEW test: rank-one collapse at large ℓ.
- **A1.3 Slope energy.** $\mathbb E[(f')^2] = -k''(0) = 5/(3\ell^2)$; centering leaves derivatives
  unchanged; per unit expected variance the factor is $5/(3\ell^2 v(\ell))\to 12$ (slope energy of
  $\sqrt{12}(x-\tfrac12)$). The brief's $\tfrac53 a_i^2\rho_i$ vs $a_i^2 v(\ell_i)$; in the package
  $a_i^2 v$ is replaced by the exact $s_i$, so the *theoretical* slope share is
  $s_i\cdot 5/(3\ell_i^2 v(\ell_i))$ normalized. NEW test: mean raw-draw slope energy vs kernel
  curvature (isolates the rescale as the source of the A1.4 ratio).
- **A1.4 Draw and exact rescale.** $Z=$ grid ∪ nodes; $F$ from `eigh`, clip at $10^{-12}\lambda_{\max}$,
  **no jitter** (sd-1e-4 white noise corrupts smooth components' slope labels); $r=F\xi$;
  $\hat m=\sum w_q r(t_q)$, $\hat V=\sum w_q r(t_q)^2-\hat m^2$;
  $f_i=\mathrm{sign}\cdot\sqrt{s_i/\hat V}\,(r-\hat m)$. **What "exact" means:** $\hat{\mathbb E}f_i=0$
  and $\widehat{\mathrm{Var}}f_i=s_i$ hold by algebra *under $\hat\nu$*; the spline interpolates
  the nodes exactly because they are knots. Under $\nu$ the gap is the GL error on a piecewise
  cubic, quantified by QMC in `tab_grid_summary`. Never write $\mathrm{Var}_\nu f_i=s_i$ without
  the hat. Realized-vs-theory slope ratio ($\mathbb E[SE/\hat V]\ne\mathbb E[SE]/\mathbb E[\hat V]$,
  1.2–1.8 by ℓ) → `tab_slope_ratio` with N and SE; consequence: `g` is a realized label and
  design-rank claims use theoretical shares (R13).
- **A1.5 Product interactions.** $h=c\,u_iu_j$ with share-1 factors; Fubini +
  $\hat{\mathbb E}u_j=0$ ⇒ $\mathbb E[h|x_i]=0$, $\mathbb E[hf_i]=0$ (note $\mathbb E[u_if_i]\ne0$
  generally), $\mathrm{Var}h=c^2$; $s_{ij}=c^2$, $\gamma=\sum s_{ij}$; the budget
  $\mathrm{Var}f=\sum s_i+\gamma=1$ needs pairwise uncorrelatedness (independent centered
  mains, disjoint pairs). `tab_orthogonality` re-measures over the grid's 80 nonzero blocks.
- **A1.6 Rotation.** $z=\tfrac12+R_\theta(x-\tfrac12)$ on disjoint pairs; extended domain
  $[\tfrac12-\tfrac{\sqrt2}{2}-0.01,\ 1-\text{that}]$, $n_{\mathrm{ext}}=\lceil(z_{hi}-z_{lo})(n-1)\rceil+1=1469$,
  $G=1533$ (R7); contraction rejected (lengthscale × $|\cos\theta|+|\sin\theta|$).
  (i) *Mean breaks*: $z_a$'s marginal is a trapezoid, not $U[0,1]$, so $\mathbb E\phi_p\ne0$ off
  $90°\mathbb Z$; $\mu=\sum_p\hat{\mathbb E}\phi_p$ by 64×64 GL. (ii) *Variance breaks*:
  $\kappa=(\sum_p\widehat{\mathrm{Var}}\phi_p+\sum_{\text{unpaired}}s_i+\sum c^2)^{-1/2}$;
  $f=\kappa(\Sigma-\mu)$; mean restored to roundoff, variance shift-invariant, argmax location
  invariant, $f^\star=\kappa(\Sigma\max-\mu)$ (R30). (iii) *ANOVA*: under a product measure the
  first-order term of $a$ is $\mathbb E_{x_b}\phi_p-\mathbb E\phi_p$, so
  $s_a^{\mathrm{axis}}=\kappa^2\mathrm{Var}_{x_a}\mathbb E_{x_b}\phi_p$; the block remainder is the
  variance of the second-order ANOVA term, hence $\ge0$, $=0$ iff $\theta\in90°\mathbb Z$, with the
  coordinate **swap** at odd multiples; $\gamma^{\mathrm{axis}}=1-\sum s^{\mathrm{axis}}=\kappa^2\sum_p\text{rem}_p$
  while $\gamma$ stays 0. **R28**: the angle does not index difficulty, the recorded
  $\gamma^{\mathrm{axis}}$ does → `tab_rotation_angle`. NEW test: $\sum s^{\mathrm{axis}}+\gamma^{\mathrm{axis}}=1$
  *and* $\gamma^{\mathrm{axis}}=\kappa^2\sum\text{rem}_p$ on a rotated variant (the second is the
  non-vacuous half).
- **A1.7 The maximum $f^\star$.** Separability over disjoint blocks; 1-D exact (piecewise-quadratic
  derivative, `roots()`); 2-D by knot-grid scan (interaction) or 1024² x-space scan (rotation, R8)
  + L-BFGS-B with analytic gradient. **Accuracy statement, verbatim policy:** "re-optimizing from
  the returned point with ftol 1e-18 / gtol 1e-14 improves the value by exactly 0.0 on every paired
  block of the grid" (`tab_fstar_reopt`); a gap against a finite reference grid bounds the grid,
  never the method — that figure was wrong three times on the branch. **Sign-convention box**:
  $f^\star$ is a maximum, $r_t=f^\star-\max_{s\le t}f(x_s)$; the SAASBO code in this repo
  *minimizes*; negate at the call site.
- **A1.8 Other generators.** Sinusoid $\omega(\ell)=\sqrt{5/(3\ell^2v)}/(2\pi)$ with the R11 caveat
  (match only for $\omega\ge1$; 1.02× at ℓ=0.08 → 1.86× at ℓ=3); monotone rejection (acceptance
  ≈0.66 at ℓ=3) with a fair direction coin; R33: `sign` is consumed in `from_raw` and marginally
  unobservable.

**Figures: none.** Every claim is an identity or a number in a generated table; the one tempting
plot ($v(\ell)$ vs $5/(36\ell^2)$) is carried by the ratio column of `tab_v_ell`.

### A2 Family reference

`tab_families` (generated from `FAMILIES`/`STUDY_GRID` so parameters cannot drift), then 14
entries with a fixed shape: *parameters* / *what it isolates* (Design-brief §3 wording) /
*measured* (its `tab_grid_summary` row + variant table). Facts each must state: `aligned10_sin`
shares $S$ and shares with `aligned10` but not draws; `interaction_g0.00` carries two zero-weight
pairs (not an "aligned5"); `rotated_t0` lives on the extended grid ($G=1533$), not bit-identical to

`tab_anti_aligned` (theoretical Spearman −1, pooled realized ≤ −0.7, per-seed unreliable, R13);
`decoupled` → `tab_decoupled`; rotated → `tab_rotation_angle` + the R28 sentence.

### A3 API and file format

A3.1 public surface (lazy root exports, torch-free; `make_family`, `build`, `FamilySpec` 12
fields, `streams`/`noise_rng`/`select_active`/`select_pairs`, `SyntheticObjective`, `Labels` →
`tab_labels_fields`, one paragraph each for `Component`/`Interaction`/`PairRotation`; `ACTIVE_EPS`
recorded not enforced). A3.2 seeding (D6): `SeedSequence(seed).spawn(3)`, nesting of $S$ across

`0x4E4F`; consequences with `test_seeding.py` citations. A3.3 files: `tab_npz_json_layout`;
**rank order vs coordinate order** (`npz["active"]` is the rank→coordinate map; `npz["s"][k]` is

`inter_values` rows $2p, 2p+1$; JSON `NaN` (R6), tuples (R9), `version` 1, `mu` stored, `load`

(R37, dotfiles silent). A3.5 BoTorch: `_is_minimization_by_default=False`, `_optimal_value=f_star`,
`evaluate_true` negate-agnostic, `forward` flips (R38); **second sign box**:
`SyntheticObjectiveTestFunction(obj, negate=True)` or `-obj(X)` before anything here that minimizes.

### A4 Design decisions — fixed shape *decision / why / check (function, test)*

D1 exact $f^\star$; D2 rotation + R7 + R8 + R30 + R28; D3 spline storage, no jitter, knot dedup;
D4 monotone rejection + R33; D5 sinusoid + R11; D6 seeding; **R5 deterministic archive — the

## Verification

- **Numbers**: `python docs/thesis/regen_tables.py --check` (exit 1 on any diff), also via
  `pytest -m slow tests/test_thesis_appendix.py`. Closed-form tables diff exactly; draw-dependent
  tables diff exactly *on the thesis machine* and their captions name the grid (manifest hashes)
  they describe; `tab_environment` is never diffed.
- **Derivations**: every identity cites an existing test or one added in
  `tests/test_thesis_appendix.py`; `pytest -q` stays the single command (currently 297 passing).
- **LaTeX**: `latexmk -pdf -interaction=nonstopmode -halt-on-error standalone_main.tex`, then
  `chktex -q` on fragments if present; fallback `lint_tex.py` (balanced braces/envs, `\input`
  targets exist, every `\ref` resolves, labels prefixed `app:so:`, no `\documentclass` in
  fragments, no undefined macro, no raw `\mathrm{Var}`/`\sigma`/`\lambda`).
- **Standalone-ness**: compile the wrapper from a scratch copy containing only `docs/thesis/`.
- **Nothing in `data/` is touched; nothing in the ledger is copied as a number.**

## Risks → mitigations

1. Notation drift from Design-brief.md → one macro file, the symbol checklist, the lint grep;
   the $g_i$ overload resolved explicitly.
2. Over-claiming "exact" → A1.4 states exactness under $\hat\nu$ and quantifies the $\nu$ gap.
3. ANOVA under rotation mis-stated → derived from the product-measure ANOVA definition, with
   non-negativity, the 90° swap and shift-invariance each tied to a test.
4. Stale numbers → none typed by hand; the four discrepancies found in exploration are the
   evidence; $f^\star$ accuracy restricted to the re-optimization-gain form.
5. Reintroducing the false `np.savez` mtime claim in A4 → explicit note in Task 6.
6. Platform-dependent draws → captions name the archived grid; A3.3 recommends archiving it.
7. Scope creep → LaTeX + one script + one test file + one lint; no figures; 4-target Makefile.
