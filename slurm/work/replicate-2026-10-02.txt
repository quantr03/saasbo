# The R2-D2 study's full replicate (stage 4) on 2026-10-02, for slurm/r2d2_packed.sbatch at K = 8
# per task. The design is 4 R2-D2 cells x 8 objective families x 10 seeds (0-9) = 320 runs; the
# pilot already ran 40 of them (every cell on aligned10 and decoupled, seeds 0-4), and those 40 are
# left out, so this list holds the other 320 - 40 = 280. Submit from $WRKDIR/saasbo with TMPDIR
# unset (the launcher's directives set gpu-h200-141g-ellis and ellis_users):
#   bash slurm/submit_chain.sh slurm/r2d2_packed.sbatch 3 \
#       --export=ALL,WORK=slurm/work/replicate-2026-10-02.txt --array=0-34 --mem=200G
#
# Order: by cell (additive/amplitude_r2d2, product/amplitude_r2d2, additive/lengthscale_r2d2,
# product/lengthscale_r2d2), then by family (aligned10, decoupled, aligned3, anti_aligned,
# interaction_g0.00, g0.25, g0.50, g0.75), then by seed. The four cells differ 5-10x in run time,
# and a task whose runs are all one cell keeps its GPU fully used until they end together; a task
# that mixed a fast cell with a slow one would leave the GPU part-idle once the fast runs finish.
# Each cell has 70 runs (aligned10 and decoupled seeds 5-9, the other six families seeds 0-9).
#
# Task i is runs 8i+1 .. 8i+8 below (comments and blanks skipped; the launcher slices the whole
# file, so the "# task" markers are only for reading): 280 runs = 35 tasks, --array=0-34.
#   additive/amplitude_r2d2    runs   1-70   tasks  0-7 whole, task 8 runs 65-70
#   product/amplitude_r2d2     runs  71-140  task 8 runs 71-72, tasks  9-16 whole, task 17 runs 137-140
#   additive/lengthscale_r2d2  runs 141-210  task 17 runs 141-144, tasks 18-25 whole, task 26 runs 209-210
#   product/lengthscale_r2d2   runs 211-280  task 26 runs 211-216, tasks 27-34 whole
